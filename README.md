# Sitio personal del Dr. Ronald Paucar Curasma

Sitio en Jekyll para GitHub Pages. Para actualizar el contenido, edita los archivos YAML de `_data/` desde GitHub o desde un editor de texto.

| Archivo | Contenido |
| --- | --- |
| `perfil.yml` | Biografía, retrato, cargos y perfiles académicos |
| `formacion.yml` | Grados y estudios |
| `proyectos.yml` | Proyectos financiados y subvenciones |
| `publicaciones.yml` | Artículos, año, tema y enlace |
| `ibpt.yml` | Modelo, fases, aplicación y enlaces de difusión |

GitHub Pages puede construir el sitio desde `main` y la raíz del repositorio. Para una vista previa local con Ruby y Bundler, ejecuta `bundle install` y `bundle exec jekyll serve`.

Las fotografías del perfil y la capacitación proceden de CTI Vitae y de la nota institucional de la UNAT enlazada en el sitio.
